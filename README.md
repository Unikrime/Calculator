# 🧮 Calculator Project

Учебный проект для практического освоения программирования: путь от создания базовой консольной логики на Java до интерактивного веб-приложения.

---

## ☕ 1. Console Calculator (Java)
Консольный калькулятор, написанный на Java в рамках изучения базовых конструкций языка и работы с системой контроля версий Git.

### Возможности:
* Базовые арифметические действия (`+`, `-`, `*`, `/`)
* Защита от деления на ноль

### Стек:
* **Язык:** Java 21
* **Инструменты:** Antigravity IDE / VS Code, Git

---

## 🌐 2. Web Calculator (HTML, CSS, JS)
Браузерная версия калькулятора с современным графическим интерфейсом.

### Возможности:
* Арифметические операции (`+`, `-`, `*`, `/`, `.`, `%`)
* Управление вводом: полная очистка (`AC`) и удаление последнего символа (`C`)
* Защита от некорректного ввода (нельзя поставить два знака подряд, блокировка ошибочных операторов)
* Сетка интерфейса на **CSS Grid** с поддержкой растягивания кнопок (`grid-row: span 2`)
* Адаптивная центровка на **Flexbox** и плавные анимации (`transition`) при наведении и клике

### Стек:
* **Frontend:** HTML5, CSS3, JavaScript (ES6)
* **Инструменты:** Git Bash, Antigravity IDE / VS Code
